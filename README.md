# novel-previews

웹소설 집필 과정에서 지인들에게 초안을 미리 보여주고 피드백을
받기 위한 저장소입니다. 작품별·화별로 폴더를 나눠 관리합니다 —
비교나 미리보기가 필요할 때마다 새 저장소를 만들지 않습니다.

## 읽으면서 바로 코멘트 달기

**[전체 목록 열기 →](https://multicg.github.io/novel-previews/)**

문장을 마우스로 드래그해서 선택하면 "💬 코멘트 달기" 버튼이 떠요.
누르고 코멘트를 남기면 이 저장소에 새 이슈로 등록됩니다(제출 시
GitHub 로그인 필요). 특정 문장이 별로였거나 좋았으면 짧게라도
남겨주세요 — "재밌었어요" 같은 전체 감상은 아래 투표 스레드에
남겨주시고, 여기는 "이 문장 어색해요" 같은 구체적인 코멘트용입니다.
