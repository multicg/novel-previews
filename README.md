# novel-previews

웹소설 집필 과정에서 지인들에게 초안을 미리 보여주고 피드백을
받기 위한 저장소입니다. 작품별·화별로 폴더를 나눠 관리합니다 —
비교나 미리보기가 필요할 때마다 새 저장소를 만들지 않습니다.
