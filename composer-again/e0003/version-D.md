3화

새벽 두 시에 채보가 끝났다. 프로듀서가 열 번쯤 물었다. "이
마디는 정박이에요, 아니면 살짝 밀려요?" 유준은 그때마다 직접
쳐서 보여줬다.

"수고했어요." 프로듀서가 처음으로 웃었다.

첫차를 기다리며 학교 과제를 마무리했다. 눈이 반쯤 감겨 있었다.

/

작곡실습 강의실. 백 교수가 말했다. "차유준 학생, 이번 과제는
그나마 낫네요." 그러다 미간을 좁혔다. "그런데 이 4마디, 왜
갑자기 진행이 뒤바뀌어요?"

어젯밤 그 진행이 무의식중에 과제에 옮겨져 있었다.

"…죄송합니다. 다시 보겠습니다." 진짜 실수였다.

백 교수는 줄을 긋지 않았다. 한참을 훑어보다가 오선지를 내려놨다.
"…이상한데. 이론상으론 틀렸는데, 왜 나쁘지 않지." 결론은
못 내렸다. "일단 넘어가죠."

*어제는 5도가 정석이라며.* 속으로만 항의했다.

/

점심시간, 전화가 울렸다. 강태오였다.

"유준아, 대박 소식. 위에서 데모 컨펌 났어. 재계약 확정."

"오, 다행이다." 진심이었다.

"그리고." 강태오가 뜸을 들였다. "프로듀서님이 너 얘기 위에
흘렸나 봐. 세션으로 좀 불러도 되냐고. 알바비도 나온대."

"나 그냥 학생이야, 형."

"그니까 그게 신기하다는 거 아니냐." 강태오가 웃었다. "너 진짜
뭐 숨기는 거 없어?"

"없어." 유준이 대답했다. 거짓말은 아니었다. 짚이는 게 없었으니까.

/

오후, 동기 재현이 다가왔다. "야, 너 오늘 과제 뭐야. 교수님이
너 칭찬하는 거 처음 봤어."

"어쩌다 보니." 유준이 얼버무렸다.

"설마 연애하냐?"

"아니거든." 유준은 대답 대신 어깨를 으쓱했다. 설명할 방법이
없었다.

/

집으로 가는 길, 이어폰에서 낯선 곡이 나왔다. 오래된 포크 음악.

세 소절쯤 지났을 때 걸음이 느려졌다.

코드 진행이—3도였다.

다음 마디가 어떻게 흘러갈지 정확히 알 것 같았다. 소름이
훑고 지나갔다. 이어폰을 뺐다.

화면에는 아티스트명이 "Unknown"으로만 떠 있었다.

그날, 유준은 처음으로 알았다 — 연주하지 않아도 되는 종류의
확신이 있다는 걸.
